# Data source and curation notes

The starter dataset is intentionally small and uses organization-level descriptions and broad program categories. It is a demonstration dataset, not a comprehensive directory or an endorsement. The project team should review each source page before formal evaluation and record an updated access date.

Coverage tags such as “India; multiple states” are broad discovery labels, not confirmed current operating-area lists. Verify exact locations and programs directly with the organization before making a donation decision. The application displays this limitation.
