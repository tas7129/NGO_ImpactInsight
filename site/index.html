What makes it an agent?

It keeps your preferences, decides when a follow-up is needed, chooses whether to clarify or search, uses the NGO directory as a tool, then shows the actions it took. It does not donate, rate, certify, or verify NGOs.

The college project

Technology should help people make their own choices.

NGO ImpactGuide is a BE CSE mini-project exploring a bounded Agentic AI workflow for donor decision support. Its sample records are curated from public organization pages.

Download project report ↓View presentation ↗

The problem

NGO program information is scattered and difficult for donors to compare.

✦
The approach

Preference clarification, transparent filtering, comparison, and source links.

⌂
Built with

HTML, CSS, and JavaScript with a curated JSON dataset. The evaluator needs no account or installation.

✓
Project evaluation

15 automated checks passed for the Python prototype: preference parsing, clarification, search, comparison, data handling, and fallback behavior.

A responsible boundaryThese are relevance suggestions based on a small sample—not an NGO rating, certification, legitimacy check, or guarantee of impact. Please verify details with the organization before donating.

Project objectives
  • Help donors describe what they care about.
  • Clarify broad requests before searching.
  • Compare relevant organization information and sources.
  • Evaluate the Python prototype with functional tests.
Agent workflow
Donor goal→Understand preferences→Clarify or search→Show sourced matches

The browser agent applies supported preference rules, chooses a follow-up or directory search, then shows an action trace.

Data and evaluation

The demonstration uses 12 curated sample records with organization descriptions, broad location labels, program tags, source links, and source dates. The Python prototype passed 15 automated checks; that result does not certify the real-world accuracy of the records.

Scope and limits

One donor uses the site at a time. The directory is read-only, preferences are kept only in the current page session, and the site does not process donations, contact NGOs, verify legitimacy, or guarantee outcomes.
